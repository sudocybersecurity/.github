## 🇳🇱 Wat wij doen

Sudo Cybersecurity zorgt dat servers, clusters en beheer technisch doen wat het beveiligingsbeleid belooft. Aantoonbaar, en zo dat het zo blijft.

- **Platformbeveiliging doorgelicht**: hoe staan uw Linux-servers, containerplatforms en beheerprocessen ervoor?
- **CIS-hardening van servers**: elke instelling in code, herhaalbaar en controleerbaar
- **Kubernetes- en OpenShift-beveiliging**: RBAC, network policies, pod security, secrets en image provenance
- **Beveiligingsmaatregelen technisch inrichten**: de technische kant van uw Cbw/NIS2/BIO-maatregelen
- **Doorlopend beheer en controle**: configuratie bewaken, benchmarks bijhouden, elk kwartaal rapporteren
- **Interim Security Engineering**: tijdelijk een ervaren security engineer in uw team

Wij werken voor Cbw-plichtige organisaties, SaaS-leveranciers aan zorg en overheid, en MSP's (ook white-label).

## 🇬🇧 What we do

Sudo Cybersecurity is a Dutch security engineering company. We make sure servers, clusters and operations actually do what the security policy promises, in a way you can prove.

Platform security assessments · CIS hardening with Ansible · Kubernetes and OpenShift security · NIS2 technical controls · Ongoing configuration management · Interim security engineers

## Wat wij aanraden, doen we zelf

- **Open source waar het kan.** Intern draaien we op Debian, KVM, Proxmox, Forgejo, Docmost, Wazuh en Hugo.
- **In Nederland, in eigen beheer.** Onze systemen en website draaien op eigen servers in Nederland. Waar we externe diensten nodig hebben, kiezen we bij voorkeur Nederlandse of Europese aanbieders.
- **Zo weinig data als nodig.** Onze website gebruikt geen cookies, analytics of trackers, en host zijn eigen lettertypes.
- **Een kleine voetafdruk.** Een statische site van zo'n 30 kB, en liever één goed benutte server dan meerdere die stilstaan.
- **Eerlijk over wat nog niet klopt.** Voor e-mail en agenda gebruiken we nog Microsoft 365. We bekijken alternatieven en stappen over waar dat kan zonder klanten te hinderen.

Onze eigen code en configuratie staan op Forgejo in Nederland. Op GitHub delen we wat we openbaar maken.
